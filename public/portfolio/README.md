# Portfolio images

Drop nail set photos here. They will be served at `/portfolio/your-file-name.jpg`.

**Suggested format:** JPG or WebP, ~1200px wide, under 500 KB when possible.

**Naming:** Use short, descriptive names (e.g. `chrome-french-tips.jpg`, `soft-pink-ombre.webp`).

After you add files, we will wire them up on the home (Portfolio) page.
